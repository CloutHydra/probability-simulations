# Probability Simulations Coursework

Two Python exercises demonstrating random sampling and probability-based decision making.

## Projects

### Monte Carlo Estimation of Pi
Generates random `(x, y)` points inside a square and checks whether each point lies inside the unit circle. The fraction of points inside the circle is used to approximate pi.

The program also visualizes the sampled points so the geometric basis of the Monte Carlo estimate is visible.

Run:
```bash
python monte_carlo_pi.py
```

### Roulette-Wheel Selection
Implements a simple weighted random decision rule:
- 80% probability: move forward;
- 10% probability: turn left;
- 10% probability: turn right.

Run:
```bash
python roulette_wheel_selection.py
```

## Skills Demonstrated
Python, random sampling, Monte Carlo methods, probability distributions, conditional logic, Matplotlib visualization.

## Context
These programs were completed as part of university coursework and are published here as examples of Python programming and probability practice.
